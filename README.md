## Layihənin Qısa İzahı
Bu layihə Git və GitHub praktiki tapşırığını yerinə yetirmək üçün hazırlanmışdır. Layihə çərçivəsində sadə veb səhifə və Python proqramı yaradılmış, versiya nəzarət sistemi (Git) vasitəsilə idarə olunmuşdur.

---

## Layihənin Tərkibi
* **`index.html`**: İstifadəçinin şəxsi məlumatlarını, maraqlandığı sahələri və CSS stillərini ehtiva edən semantik HTML səhifəsi.
* **`app.py`**: İstifadəçidən yaş məlumatını daxil etməsini istəyən və növbəti il neçə yaşı olacağını hesablayan interaktiv Python proqramı.

---

## Git və GitHub Əməliyyatları
* **Branch-lar**: İş prosesini ayırmaq üçün `feature-html` və `feature-python` branch-ları yaradılmışdır.
* **Merge**: Hazırlanan xüsusiyyətlər əsas `main` branch-ına uğurla birləşdirilmişdir (merge olunmuşdur).
* **Commit History**: Bütün dəyişikliklər aydın və məntiqli commit mesajları ilə qeydə alınmışdır.
